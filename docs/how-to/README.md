# How-to guides

Task-oriented guides for a reader who already knows the basics and wants to
accomplish something specific. A how-to guide answers "how do I do X," not
"why does the tool work this way" (see `../explanation/`).

Future guides will cover importing a network and evaluating mitigation
options after those workflows are implemented and verified. Neither the
four-sheet import process nor an automated budget-constrained fixes search
is available through the current application.

For existing functionality, see the [README](../../README.md) and the
CLI help output.
