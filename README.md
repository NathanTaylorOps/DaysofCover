# Days of Cover

Supply chain stress test: how long can you keep shipping if a supplier, port or route goes down, and what is the cheapest fix.

Days of Cover simulates a multi-tier supply network under disruption and answers the question a general manager actually asks: if this supplier, port or route goes down for N weeks, how long before we miss customer orders, what does it cost, and what is the cheapest way to make that not happen. It is built on the time-to-survive and time-to-recover method (Simchi-Levi et al., 2015), with a discrete-event simulation as the source of truth for every dollar it reports.

This is the first commit. The engine, validation suite and hosted demo follow; each release tag carries a README that describes exactly what exists at that tag.

Built with AI-assisted development.
